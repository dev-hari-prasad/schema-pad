# Schema Pad for VS Code

Design, understand, and ship database schemas without leaving your editor.

Schema Pad is a visual database design workspace for developers and technical teams. Model
tables and relationships on an interactive ERD canvas, explore changes with AI, and move
between visual design, ORM schemas, and SQL without losing sight of the data model.

## One canvas, multiple workflows

- Design tables, fields, relationships, and groups visually.
- Generate code for Prisma and Drizzle ORM.
- Generate SQL for PostgreSQL and MySQL workflows.
- Keep Prisma files synchronized with the canvas in both directions.
- Use AI assistance to understand, create, and refine schemas.
- Share a clear data model for implementation, reviews, onboarding, and planning.

Prisma synchronization is built into the VS Code experience, but it is only one part of
Schema Pad's broader database design workflow.
